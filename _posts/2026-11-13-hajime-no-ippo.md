## 結論：最初の依頼は「読むだけ」の仕事から始める

Claude Codeの第一歩は、インストールしても、いきなりコードを書かせないことです。最初の依頼は「このフォルダの中身を要約して」のような、読み取りだけの仕事から。安全ですし、動きの感覚もつかめます。この記事では、インストールから最初の依頼までの手順をまとめます。つまずきポイント付きです。

## Claude Codeとは何か

Claude Codeは、Anthropicが提供するコーディングエージェントです。ターミナル（コマンドを入力する黒い画面）の中で動き、ファイルの読み書き、コマンドの実行、調査や文書作成までを、自然言語の依頼で代行します。チャットで答えをもらうのではなく、「作業そのものを任せる」道具だと考えると分かりやすいです。

## 手順1：インストールする

前提として、公式の案内に従い以下のいずれかでインストールします。

- ネイティブインストーラ（macOS / Linux）: 公式サイトの案内に沿ってコマンドを1行実行
- Windows: 公式の案内に従ってインストール（WSL環境が必要な場合があります）
- npmを使う方法もあります。Node.js 18以上を入れたうえで `npm install -g @anthropic-ai/claude-code`

インストールできたら、ターミナルで `claude --version` と入力し、バージョンが表示されるか確認します。表示されれば第一関門は通過です。

つまずきポイント: npmで入れた場合に権限エラー（EACCES）が出ることがあります。その場合は公式ドキュメントのトラブルシューティングに沿って、npmのグローバルインストール先を変更するのが定石です。安易に管理者権限で実行し直すのは避けましょう。

## 手順2：サインインする

作業フォルダに移動して `claude` と入力すると、初回はサインインが求められます。ブラウザが開きます。Anthropicのアカウントでログインして、ターミナル側に戻れば完了です。利用にはClaudeの有料プラン、またはAPI利用の契約が必要です（最新の料金条件は公式サイトで確認してください）。

## 手順3：最初の依頼は「読むだけ」から

起動したら、まず読み取りだけの依頼をしてみます。

```
このフォルダにあるファイルの一覧と、それぞれの役割を教えてください。変更はしないでください。
```

ポイントは最後の一文です。「変更はしないでください」と明示すると、最初の体験が事故なく終わります。Claude Codeはファイル変更やコマンド実行の前に許可を求める設計ですが、最初は依頼側でも「読むだけ」と線を引くのが安全です。

## 手順4：2回目の依頼で「小さく書かせる」

感覚がつかめたら、小さな作成を任せます。

```
フォルダ内のメモをもとに、要点を3行にまとめた summary.md を新規作成してください。
```

新規ファイルの作成なら、失敗しても消せば済みます。「既存ファイルの書き換え」は、動きに慣れてからにしましょう。

## 安全に始めるための3つの初期ルール

1. **大事なフォルダでいきなり始めない** — 最初は練習用のフォルダで始めます。削除や上書きの影響がない場所で感覚をつかむこと
2. **秘密情報を置いたまま作業しない**: パスワードやAPIキーが書かれたファイルがあるフォルダでは、作業範囲を意識します（詳しくは第7夜「秘密情報を渡さないための設定」で扱います）
3. **変更前の確認を省略しない** — 許可を求められたら、内容を読んでから承認します。「全部許可」は慣れてからでも遅くありません

## 次回予告

第2夜は「CLAUDE.mdに何を書くか」です。プロジェクトの前提や約束事をファイルに書いておくと、毎回の説明が不要になります。そのまま使える雛形付きで公開します。
